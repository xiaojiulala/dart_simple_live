## 📺 专版介绍

本项目是基于开源聚合直播项目 [SimpleLive](https://github.com/xiaoyaocz/dart_simple_live) 针对 **Android TV、智能电视机顶盒及大屏投影** 进行深度定制、重构与长期维护的电视专版。

去除桌面端与手机端的冗余模块，聚焦于**大屏遥控器交互体验**、**低功耗与播放流畅度**、**无中心服务器的本地化账号安全**以及**局域网无线管理协同**。

---

## ✨ 核心特性

### 1. 纯本地化，零第三方中心服务依赖
* **账号凭据安全可靠**：B站（SESSDATA）与斗鱼（auth/dy_did）登录凭据全部在本地解密、验证与存储，绝不经过任何第三方开发者服务器，杜绝账号泄漏或远程中转服务器宕机风险。

### 2. 独创四层登录凭据自动感知与到期强提醒
* **B站 180 天长效凭据**：本地自动反解凭据过期时间戳（有效期约半年），毫秒级无网本地检测。
* **斗鱼 7 天凭据感知**：本地时间轴倒计时，剩余有效期实时掌握。
* **置顶发光系统弹幕**：进入直播间时，若未登录或即将过期（≤7天），延时投送置顶金色发光系统弹幕，提醒画质受限并引导扫码续期；关闭弹幕时自动平滑降级为底部 Toast。
* **清晰度菜单动态指示**：播放器清晰度面板直观展示登录态与剩余天数（例如 `清晰度 (B站已登录·余180天)` / `清晰度 (B站未登录·限720P)`）。
* **设置中心状态看板**：系统设置页直观展示各大平台授权有效天数与健康状态，支持一键扫码快捷续期。

### 3. 局域网 Web 控制台（手机/电脑免遥控管理）
* 电视启动后自动运行轻量级局域网 Web 后台（默认端口 `23234`，浏览器打开 `http://电视IP:23234/` 即可访问）。
* **手机秒投送**：支持将各大平台直播间链接、网页主页链接粘贴后一键投送到电视大屏播放。
* **关注与历史管理**：支持在手机/电脑浏览器中查看电视端关注列表、一键导入/导出 JSON 备份。
* **账号健康看板**：Web 控制台实时查看斗鱼、B站凭据有效天数、UID 与状态胶囊。

### 4. 深度重构的关注列表与遥控器焦点体验
* **看播防卡顿调度**：全屏看直播期间自动挂起后台轮询，把 CPU 与带宽 100% 留给播放器；退出直播间后按需校验（达到 10 分钟周期才触发刷新，未达周期零开销）。
* **双缓冲原子就位**：后台并发静默拉取所有平台最新状态并排序完毕后，**一次性整批原子就位**，彻底告别卡片逐个亮绿灯和洗牌式跳位，消除黑白闪烁。
* **退出直播间无感静默归顶**：退出播放器时，视口瞬间平稳归顶，遥控器光标**自动精准吸附在【我的关注】首个直播间卡片**上（高亮放大 1.1x），免去在长列表中手动连续按向上键回滚的疲劳。
* **动态状态胶囊指示器**：“我的关注”标题旁配有状态胶囊，刷新时显示 `[ ⟳ 刷新中... ]`，完成后转为绿色 `[ ✓ 刷新完毕 (X人开播) ]` 并于 3 秒后柔和淡出。

## 🛠️ 快速上手

1. **安装软件**：
   * 下载对应的 `.apk` 文件存入 U 盘，插到电视上通过“文件管理”或“应用安装器”完成安装。
2. **手机/电脑管理后台**：
   * 确保电视和手机/电脑连接在**同一个局域网（同一 Wi-Fi）**下。
   * 查看电视端主页或设置中显示的局域网 IP（如 `192.168.2.54:23234`）。
   * 手机浏览器直接打开该网址，即可使用手机投送链接、管理关注列表及查看账号健康状态。
3. **画质与解码建议**：
   * 电视端硬件性能差异较大，播放设置中建议保持 **硬件解码** 为开启状态。
   * B站与斗鱼高画质需扫码登录账号，软件在到期前 7 天会自动通过弹幕提醒续期，无需担心突然降画质。
